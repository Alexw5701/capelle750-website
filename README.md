# Capelle750.nl – onafhankelijke historische website

Een responsieve, zelfstandige introductiewebsite voor capelle750.nl met duidelijke melding 'website in ontwikkeling'.

## Publiceren via GitHub Pages

1. Maak een **nieuwe publieke repository** aan in het GitHub-account, bijvoorbeeld `capelle750-website`.
2. Upload de bestanden en de map `assets/` uit deze ZIP naar de hoofdmap van de repository.
3. Ga naar **Settings > Pages**, kies **Deploy from a branch**, branch `main`, map `/(root)` en sla op.
4. Stel bij **Custom domain** `capelle750.nl` in. De meegeleverde `CNAME` bevat al deze naam.
5. Configureer in het DNS-beheer van de domeinprovider de records voor GitHub Pages conform de actuele GitHub-documentatie en schakel HTTPS in wanneer beschikbaar. Wijzig bestaande DNS-records pas nadat je de huidige instellingen hebt vastgelegd.

## Techniek

- Eén pagina, alleen HTML/CSS en minimale JavaScript voor het mobiele menu
- Geen externe scripts, fonts, trackers of cookies
- Eenvoudig uit te breiden met subpagina's
- Gebouwd voor mobiel en desktop

## Inhoud en positie

De teksten onderscheiden het particuliere hobbyproject expliciet van de gemeente. Gebruik van deze website is geen uitspraak over eventuele rechten op een domeinnaam. Feiten en bronnen zijn in de site zelf gekoppeld.
